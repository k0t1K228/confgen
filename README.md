# confgen

Командный инструмент для перевода учебного конфигурационного языка
в YAML. Домашняя работа по дисциплине «Конфигурационное управление»,
вариант № 21.

## 1. Общее описание

`confgen` читает текст на учебном конфигурационном языке из стандартного
ввода, проверяет его синтаксис, вычисляет константы и константные
выражения и печатает результат в формате YAML в стандартный вывод.
Синтаксические ошибки и ошибки вычисления выводятся в стандартный
поток ошибок с указанием строки и столбца.

Синтаксический разбор выполняется специализированным инструментом
[lark](https://github.com/lark-parser/lark) (алгоритм LALR(1)).
Грамматика находится в файле `src/confgen/grammar.lark`.

Конвейер трансляции: **текст → разбор (lark) → вычисление констант →
YAML**.

Структура репозитория:

| Путь | Назначение |
|---|---|
| `src/confgen/` | исходный код |
| `tests/` | тесты (pytest) |
| `examples/` | три примера конфигураций и эталонные YAML |
| `Makefile` | сборка, тесты, запуск |
| `requirements.txt` | зависимости |
| `pyproject.toml` | настройки pytest и линтера ruff |

## 2. Описание всех функций и настроек

### 2.1. Синтаксис языка

| Конструкция | Запись | Примечание |
|---|---|---|
| Однострочный комментарий | `* текст до конца строки` | `*` должен быть первым символом строки (допускается отступ) |
| Многострочный комментарий | `{{! ... }}` | может занимать несколько строк |
| Число | `[+-]?\d+\.?\d*[eE][+-]?\d+` | экспонента обязательна: `1e0`, `-2.5E+3`; `5` не число |
| Строка | `@"текст"` | внутри нет символа `"`, допускаются переводы строк |
| Массив | `#( значение, значение, ... )` | элементы через запятую, допускается пустой `#()` |
| Словарь | `begin имя := значение; ... end` | каждая запись оканчивается `;`, допускается пустой |
| Имя | `[_a-zA-Z]+` | только латиница и `_`, цифр нет |
| Объявление константы | `let имя = значение` | без `;`, константа видна после объявления |
| Вычисление | `^[выражение]` | инфиксная форма, результат является значением |

Значения: числа, строки, массивы, словари и вычисления `^[...]`.
Структуры вкладываются друг в друга без ограничений.

**Структура программы.** Сначала идут ноль или несколько объявлений
`let`, затем ровно одно итоговое значение. Оно и становится
YAML-документом (обычно это словарь `begin ... end`).

**Выражения** `^[ ... ]`:

| Элемент | Запись |
|---|---|
| Операции | `+`, `-`, `*`, `/` |
| Приоритет | `*` и `/` выше, чем `+` и `-`; операции левоассоциативны |
| Скобки | `( выражение )` |
| Функция | `min(a, b, ...)`, минимум одного аргумента |
| Операнды | числа, имена констант, вызовы `min`, скобки |

Операнды арифметики и аргументы `min` должны быть числами. Выражение
`^[имя]` без операций возвращает значение константы любого типа
(число, строку, массив или словарь).

**Правила и ограничения:**

- Все числа читаются как `float`, поэтому в YAML они имеют вид `8080.0`.
- Слова `let`, `begin`, `end`, `min` зарезервированы.
- Повторное объявление константы с тем же именем является ошибкой.
- Повторяющийся ключ в одном словаре является ошибкой.
- Строка, начинающаяся (после отступа) с `*`, всегда комментарий.
  Поэтому в многострочном выражении не начинайте строку с оператора
  умножения: перенесите `*` в конец предыдущей строки.
- Ввод должен быть в кодировке UTF-8. Кириллица допустима в строках
  и комментариях, имена только латиницей.

### 2.2. Командная строка

```
confgen [-h]
```

| Ключ | Действие |
|---|---|
| `-h`, `--help` | показать справку и выйти |

Других настроек нет: вход всегда `stdin`, выход всегда `stdout`.
Конфигурационных файлов и переменных окружения программа не использует.

Коды завершения:

| Код | Значение |
|---|---|
| `0` | успех |
| `1` | синтаксическая ошибка, ошибка вычисления или ввод не в UTF-8 |
| `2` | неверный ключ командной строки |

При ошибке в `stdout` ничего не выводится, сообщение идёт в `stderr`:

```
Синтаксическая ошибка: строка 1, столбец 16: неожиданный токен 'end', ожидалось: ';'
Ошибка вычисления: строка 1, столбец 14: константа 'b' не объявлена
```

### 2.3. Функции и модули (`src/confgen/`)

| Модуль | Содержимое |
|---|---|
| `grammar.lark` | грамматика языка: терминалы, правила, комментарии |
| `parser.py` | `parse(text) -> Tree`: разбор, при ошибке `ConfigSyntaxError` с позицией и списком допустимых токенов |
| `evaluator.py` | `evaluate(tree)`: выполняет `let`, вычисляет `^[...]`, возвращает `float`, `str`, `list` или `dict`; класс `Evaluator` |
| `emitter.py` | `to_yaml(value) -> str`: вывод YAML, порядок ключей сохраняется, кириллица не экранируется, без якорей и маркера `...` |
| `translator.py` | `translate(text) -> str`: весь конвейер разбор, вычисление, YAML |
| `cli.py` | `main(argv, stdin, stdout, stderr) -> int`: интерфейс командной строки |
| `errors.py` | `ConfigError` и наследники `ConfigSyntaxError`, `ConfigEvalError` (поля `message`, `line`, `column`, `title`) |
| `__main__.py` | точка входа `python -m confgen` |

## 3. Сборка проекта и запуск тестов

Требования: Python 3.10 или новее, `make`, `git`. Проверено на Arch Linux
с Python 3.14.

```bash
git clone <адрес репозитория>
cd confgen
make install     # создать .venv и установить зависимости
make test        # запустить тесты (pytest)
make lint        # проверить стиль и сложность (ruff)
make examples    # вывести результат трансляции всех примеров
make run         # запустить транслятор (ввод из stdin)
make clean       # удалить кэши
```

Без `make`:

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest
PYTHONPATH=src .venv/bin/python -m confgen < examples/web_service.conf
```

Зависимости (`requirements.txt`): `lark`, `PyYAML`, `pytest`, `ruff`.

Тесты (`tests/`):

| Файл | Что проверяет |
|---|---|
| `test_parser.py` | все конструкции синтаксиса, вложенность, ошибки и их позиции |
| `test_evaluator.py` | константы, арифметика, приоритеты, `min`, ошибки вычисления |
| `test_emitter.py` | формат YAML, порядок ключей, кавычки, обратное чтение |
| `test_cli.py` | потоки, коды завершения, реальный запуск процесса |
| `test_examples.py` | сравнение примеров с эталонами и наличие всех конструкций |

## 4. Примеры использования

### Простой запуск

```bash
printf 'let n = 2e0\nbegin\n  double := ^[n * 2e0];\n  list := #(@"a", ^[n + 1e0]);\nend\n' | make run
```

Результат:

```yaml
double: 4.0
list:
- a
- 3.0
```

### Запуск из файла и сохранение результата

```bash
PYTHONPATH=src .venv/bin/python -m confgen < examples/shop_order.conf > order.yaml
```

### Ошибки

```bash
printf 'begin a := 1e0 end' | PYTHONPATH=src .venv/bin/python -m confgen
# Синтаксическая ошибка: строка 1, столбец 16: неожиданный токен 'end', ожидалось: ';'

printf 'begin x := ^[1e0 / 0e0]; end' | PYTHONPATH=src .venv/bin/python -m confgen
# Ошибка вычисления: строка 1, столбец 20: деление на ноль
```

### Примеры из разных предметных областей (`examples/`)

| Файл | Область |
|---|---|
| `web_service.conf` | администрирование: порты и лимиты веб-сервиса |
| `game_balance.conf` | разработка игр: баланс героя и врагов |
| `shop_order.conf` | торговля: заказ с расчётом скидки и налога |

Рядом с каждым примером лежит эталонный результат (`*.yaml`).
Фрагмент `examples/shop_order.conf`:

```
let bookPrice = 1.5e3
let taxRate = 2.5e-1
let subtotal = ^[bookPrice * 2e0 + 5e1 * 1e1]
let discount = ^[min(1e3, subtotal / 1e1)]
let total = ^[(subtotal - discount) * (1e0 + taxRate)]
```

даёт в результате `subtotal: 3500.0`, `discount: 350.0`, `total: 3937.5`.
